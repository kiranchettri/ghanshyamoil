# GHANSHYAM OLI Admin Panel

Vanilla HTML, CSS, and JavaScript CMS demo. Open `login.html` and use the clearly marked demo credentials: `admin@ghanshyamoli.com` / `admin123`.

The localStorage session is only a frontend demo and is not real authentication. Replace `js/auth.js` methods with a backend session/JWT flow before production. Demo records live in `js/data.js`; page renderers are shared through `js/admin.js` and `js/pages.js`.
